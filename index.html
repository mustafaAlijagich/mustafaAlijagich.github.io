Blender Add-ons

Tools that save hours in Blender: clean topology in one click, and models that open as real solids in your CAD software.

Auto RetopoMesh to CAD

Auto Retopo

One-click automatic retopology. Turn scans, sculpts and messy meshes into clean, quad-only topology that sticks to the original surface.

Coming soon

$19 one-time · Blender 4.2 and newer · Windows, macOS, Linux

Auto face count

Pick a detail level (Low, Medium, High, Ultra). The add-on measures how much detail is lost and finds the smallest mesh that keeps it.

Fine detail layer

A Multires layer shaped to the original keeps pores, relief and scan texture on top of the clean base mesh.

Works on bad input

Holes, overlaps, joined parts and heavy scans are cleaned automatically with voxel remesh before quad meshing.

Symmetry and sharp edges

Mirror on X, Y or Z with a welded seam. Keeps hard-surface edges and open borders.

Relax & Project

Smooths the mesh along the surface and snaps it back, also on selected vertices after manual edits.

Analyze and bake

Quad percentage, poles, deviation from the original, and a one-click normal map bake with UVs and material.

Where to find it

3D Viewport sidebar (N), tab Retopo: select a mesh and click Auto Retopology.

Mesh to CAD

Bring Blender models into SolidWorks, Fusion, Inventor and other CAD software as real solids: set the true size from one known measurement and export a clean STEP file in millimetres.

Coming soon

$29 one-time · Blender 4.2 and newer · no extra libraries needed

Real size in one step

Select an edge or two points with a known length, type the real value (for example 120 mm) and the whole model scales to it.

True cylinders and cones

Holes, shafts and chamfers become real cylindrical and conical faces with circular edges, so diameters and axes can be picked in CAD.

Flat faces merged

Coplanar triangles become one CAD face. A cube exports as 6 faces, not 12 triangles.

Check before export

Size in mm, open edges, non-manifold edges, flipped normals, volume, and a warning when the file will be too heavy for CAD.

Multiple bodies

Each object, or each loose part, becomes its own named solid body in one STEP file.

Standard STEP

AP214 in millimetres, modifiers and transforms applied, mirrored objects handled correctly.

Where to find it

3D Viewport sidebar (N), tab CAD, or File → Export → STEP for CAD (.step).

Install

  1. Download the add-on .zip after purchase.
  2. In Blender: Edit → Preferences → Get Extensions → Install from Disk and select the zip.
  3. Open the 3D Viewport sidebar with N and find the add-on tab.
